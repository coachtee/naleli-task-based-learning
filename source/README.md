# /source — Course design blueprint and provenance

## 1. Digital Foundation 90-Day Workbook

**File:** `Naleli_Task_Based_Digital_Foundation_90_Day_Workbook.xlsx`

This is the **master course-design blueprint** for the first Digital
Foundation programme, generated by/for the Naleli Task-Based Learning
project. It defines the 90-day structure this app implements: `START`,
`ROADMAP`, `DAY 01`–`DAY 90`, `PORTFOLIO`, `ASSESSOR`, and `RESOURCES`
sheets, covering the daily tasks, learning progression, stages, evidence
requirements, review questions, portfolio structure, assessor structure,
and capstone structure.

This workbook is **Naleli-owned planning content** and is committed to this
public repository per the project brief. It is not modified in place by
app/content development — see "Versioning" below.

## 2. Source course / manual references

The workbook's own `RESOURCES` sheet records what it was built from:

| Source | Reference | Use |
|---|---|---|
| Uploaded course PDF | `digital-literacy-v3.pdf` (identified in the workbook as **CompTIA Digital Literacy**) | Primary course source used to design this workbook's day-by-day structure |
| Course structure | Modules 1–20; lessons, learning outcomes, labs/reviews and capstone | Converted into this workbook's daily task-based structure |
| Source note | Page numbers shown on each `DAY` tab | Points back to the source manual's pages for whoever holds a licensed copy |

**That source PDF (`digital-literacy-v3.pdf` / CompTIA Digital Literacy) is
a third-party copyrighted work. It has not been uploaded to this
conversation, is not included anywhere in this repository, and must never
be added here or bundled into the APK unless redistribution rights are
explicitly confirmed.** The workbook's `DAY` tabs reference the source by
lesson name and page number only — that is a citation, not a copy.

If a licensed copy of the source manual is used internally to help write
Naleli's own lesson summaries, it should be kept in a private location
outside this repository (e.g. `source/private/`, which is `.gitignore`d)
and never committed.

## 3. Course content transformation notes

The transformation this app performs is:

```
Excel workbook (design blueprint)
        ↓
Naleli-authored course content model (JSON)
        ↓
content/digital-foundation/*.json
        ↓
Android learning experience (native screens, not a spreadsheet view)
```

See `docs/CONTENT-MODEL.md` for the JSON schema and the exact field-by-field
mapping from each `DAY` tab's `Step/Task/Instructions/Evidence` columns to
the app's task model. Lesson content shown in the app
(`lessonSummary` in each `day-NN.json`) is **written fresh by Naleli** for
each day's topic — it is never copied from the source manual. Only short,
workbook-authored structural elements (task step names, the "Focus on: ..."
topic phrases, and the "SOURCE LEARNING QUESTIONS") are reused, because
those are the workbook's own original structure, not the manual's prose.

## Why this matters beyond the APK

The workbook remains useful even after the app exists — it is the course
planning document, the content-authoring reference for Days 8–90, the
QA/UAT reference, the assessor reference, the curriculum mapping reference,
and the source for migrating this same methodology to future Naleli
programmes. It must stay in the repository and stay version-controlled;
nothing about building the app supersedes it.
