# Naleli Workspace design canvas

Working files for the published canvas
(https://claude.ai/code/artifact/9a73519b-15eb-4247-97e2-b3459ff93d68).

Each `*.dc.html` is one artboard; `canvas.json` places them. Re-seeding the
canvas needs all of them, so they live here rather than in a scratch
directory that a new session would not have.

All nineteen artboards are on the light NIBS palette that ships in the app.

| Row | Artboards |
|---|---|
| Core screens | Panel, Main, MyWork, TaskWorkspace, Evidence, Assessment, Journey, Portfolio, Me |
| Orientation | OrientWelcome, OrientDigitalOps, OrientJourney, OrientMethod, OrientWhy, OrientPortfolio |
| Lesson reader | LessonReader, LessonBlocks, LessonMedia, TaskPrep |

The two newer rows are generated by `build_boards.py`, which holds the
palette in one place — the values are copied from
`app/src/main/java/com/naleli/tbl/ui/theme/Color.kt` so the mockup and the
shipping build cannot drift. Edit the generator, not the generated
`Orient*.dc.html` / `Lesson*.dc.html` / `TaskPrep.dc.html` files.

The nine core screens were re-themed from the retired dark/blue direction
by mapping their tokens and inline SVG strokes onto the light palette. Two
things needed hand-correcting afterwards, because a colour map cannot know
intent: the bottom bar stays navy with light ink (the map alone left it
orange-on-white), and Home's Current Focus card stays navy, since it is the
one anchor surface on that screen.
