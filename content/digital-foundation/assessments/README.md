# assessments/

Reserved for future formal assessment definitions (e.g. the Day 83–90
capstone rubric, or a final knowledge check) once those are authored from
the workbook's `ASSESSOR` sheet. V1 models assessment *state*
(`NOT_YET_ASSESSED / COMPETENT / NOT_YET_COMPETENT / RESUBMIT`) per task in
the Room database (see `docs/ARCHITECTURE.md`), but does not yet ship a
formal assessment content package — that lands with the V1.1 full 90-day
content pass (see `docs/ROADMAP.md`).
